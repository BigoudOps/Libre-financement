# Financements par licence

Pour chaque famille de licence : les financements dont la condition de licence est remplie, d'après les pages officielles des programmes.

Lecture : une licence approuvée par l'OSI remplit les conditions « approuvée par l'OSI » et « open source ». Les pages qui écrivent « libre » ou « reconnue » sans citer l'OSI sont signalées telles quelles.

## Licences approuvées par l'OSI

Liste de l'[OSI](https://opensource.org/licenses) : MIT, Apache-2.0, BSD 2 clauses, BSD 3 clauses, ISC, MPL-2.0, LGPL-3.0, GPL-2.0, GPL-3.0, AGPL-3.0, EUPL-1.2, Unlicense.

Presque aucune page ne distingue ces licences entre elles : permissive (MIT, Apache-2.0, BSD, ISC) ou copyleft (MPL, LGPL, GPL, AGPL, EUPL), le critère est le même. Exception : la Filecoin Foundation demande une double licence MIT et Apache 2.0.

## Licences non approuvées par l'OSI

Licences Fair Source (FSL, FCL, BUSL) et autres licences à code source disponible. Sourcebot écrit explicitement que son cœur sous FSL n'est plus sous licence open source approuvée par l'OSI ([détail](fiches/modeles-economiques.md#fair-source)).

Les programmes qui exigent une licence libre, open source ou approuvée par l'OSI sont exclus : voir les tableaux ci-dessus. Restent ceux dont la page ne pose aucune condition de licence écrite. Leurs pages parlent toutefois parfois de projets « open source » ou publics, donc l'acceptation d'une licence non OSI n'y est pas confirmée :

| Programme | Ce que dit la page |
|---|---|
| [Sovereign Tech Standards](fiches/subventions-publiques.md#sovereign-tech-standards) | vise un projet d'infrastructure numérique open source |
| [Open Technology Fund](fiches/fonds-prives.md#open-technology-fund--foss-sustainability-fund) | licence non indiquée |
| [Codex for Open Source](fiches/fonds-prives.md#codex-for-open-source-openai) | vise un projet public largement utilisé |
| [Open Collective](fiches/plateformes.md#open-collective) | aucune condition mentionnée |
| [Liberapay](fiches/plateformes.md#liberapay) | aucune condition mentionnée |

## Modèles de licence qui financent

| Modèle | Ce qu'il implique |
|---|---|
| [Fair Source](fiches/modeles-economiques.md#fair-source) | FSL, FCL, BUSL : pas open source au sens de l'OSI, conversion après un délai |
| [Double licence](fiches/modeles-economiques.md#double-licence) | exemple MySQL : GPLv2 et licence commerciale |
| [Open core](fiches/modeles-economiques.md#open-core) | fonctions commerciales séparées du cœur ouvert |

## Indépendant de la licence

Les statuts pour être payé en France ([micro-entrepreneur, CAE, association, fonds de dotation, Acre, Arce, Adie](fiches/france.md)) ne dépendent pas de la licence du projet.
