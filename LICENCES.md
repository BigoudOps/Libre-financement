# Ce que dit chaque programme sur la licence

Texte tel qu'indiqué par les pages officielles, sans interprétation.

## Licence libre ou open source exigée

| Programme | Licence demandée |
|---|---|
| [NLnet](fiches/subventions-publiques.md#nlnet) | licence libre ou open source reconnue |
| [Sovereign Tech Fund](fiches/subventions-publiques.md#sovereign-tech-fund) | approuvée par l'OSI ou compatible FSF |
| [Sovereign Tech Fellowship](fiches/subventions-publiques.md#sovereign-tech-fellowship) | OSI ou FSF Free/Libre |
| [GitHub Secure Open Source Fund](fiches/fonds-prives.md#github-secure-open-source-fund) | licence open source claire |
| [Alpha-Omega](fiches/fonds-prives.md#alpha-omega) | approuvée par l'OSI, à prouver dans la proposition |

## Modèles de licence

| Modèle | Ce qu'il implique |
|---|---|
| [Fair Source](fiches/modeles-economiques.md#fair-source) | FSL, FCL, BUSL : pas open source au sens de l'OSI, conversion après un délai |
| [Double licence](fiches/modeles-economiques.md#double-licence) | exemple MySQL : GPLv2 et licence commerciale |
