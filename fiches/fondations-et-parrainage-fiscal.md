# Fondations et parrainage fiscal

Cette fiche couvre les structures qui hébergent juridiquement et financièrement un projet libre (parrain fiscal, fondation de projets). Elles ne versent pas de bourse : elles reçoivent les dons, tiennent la comptabilité et portent les contrats. Les informations viennent des pages officielles ; ce qu'une page ne dit pas est noté « non précisé ».

## Open Source Collective

- **Type** : parrain fiscal (hébergeur fiscal) pour projets open source
- **Structure** : Open Source Collective (OSC), via la plateforme Open Collective
- **Frais** : 10 % fixes sur les fonds entrants provenant de donateurs externes. Ils couvrent « operational, legal, infrastructure, and financial services » fournis aux projets hébergés.
- **Licence** : licence open source définissant clairement les conditions d'usage ; OSC suit les listes de licences approuvées de l'OSI, de la FSF, de Debian, de Fedora et de l'OSHWA
- **Éligibilité** : projet original ou fork substantiel, avec activité récente ou usage significatif ; le candidat doit être mainteneur et pas seulement contributeur ; le projet doit être hébergé sous un dépôt d'organisation et non sous un compte personnel ; si possible, deux administrateurs ou plus sur la page Open Collective. Recommandés : consignes de contribution, documents d'accueil, code de conduite, processus de décision clair.
- **Services** : comptabilité, impôts, factures, contrats, emploi ; gestion de compte bancaire, déclarations fiscales 990 automatisées, gestion de subventions, détention de marques. OSC indique héberger plus de 2 500 projets.
- **Candidature** : lien « Apply today » sur opencollective.com/opensource/apply, qui renvoie aux critères d'acceptation et aux conditions de parrainage fiscal

**Sources** : [Open Source Collective](https://www.oscollective.org/) ; [OSC — critères d'acceptation](https://docs.oscollective.org/interested-in-joining-osc/acceptance-criteria) ; [OSC — frais](https://docs.oscollective.org/welcome-and-introduction-to-osc/fees.md)

## Software Freedom Conservancy

- **Type** : parrain fiscal à but non lucratif pour projets membres
- **Structure** : Software Freedom Conservancy
- **Frais** : les nouveaux membres versent 10 % des revenus que Conservancy traite, au profit de son fonds général
- **Licence** : « Being a FOSS project under an OSI-approved and DFSG-free license is mandatory. » Documentation sous une licence de ces listes ou sous Creative Commons (CC-BY-SA, CC-BY ou CC0).
- **Éligibilité** : communauté existante et active ; les projets de moins d'un an ou limités à une preuve de concept sont en général inéligibles
- **Services** : dons déductibles fléchés vers le projet, détention d'actifs (marques, noms de domaine, matériel), négociation et signature de contrats, soutien logistique pour les conférences, conseils juridiques de base, application des licences de copyright à la demande du projet, aide à la collecte de fonds, prise en charge des formalités administratives, accompagnement des responsables, protection partielle contre la responsabilité personnelle, organisation des élections communautaires. Conservancy ne dirige pas les décisions techniques.
- **Candidature** : courriel à apply@sfconservancy.org avec une description et l'URL du projet ; questions initiales, puis dossier complet en texte ASCII par courriel, avec le numéro de ticket en objet. Comité d'évaluation en continu ; acceptation non garantie, délai pouvant atteindre plusieurs mois.

**Sources** : [Conservancy — candidater](https://sfconservancy.org/projects/apply/) ; [Conservancy — services](https://sfconservancy.org/projects/services/)

## Software in the Public Interest

- **Type** : association fiscale pour projets associés
- **Structure** : Software in the Public Interest (SPI)
- **Frais** : « There is no cost to become or remain an associated project. » Les pages consultées ne donnent pas de pourcentage retenu sur les dons ; les frais de contrats propres à un projet sont en général payés sur ses fonds fléchés, et les frais courants de comptabilité et d'audit sont couverts par SPI.
- **Licence** : aucune licence nommée ; la page demande un projet libre et open source jugé « genuine, substantial and significant » ; le premier critère de vote est « Free Software: is the project a genuine Free Software community project? »
- **Éligibilité** : le conseil juge le statut de logiciel libre, la substance (communauté de développement établie, historique de versions) et l'importance (large usage ou importance politique ou de marché). Les contrats, dettes ou litiges existants doivent être signalés à SPI.
- **Services** : réception de dons et détention des fonds pour le compte du projet ; détention d'actifs matériels (équipement ou biens de plus de 300 $ achetés avec des fonds SPI) et immatériels (noms de domaine, marques, licences) ; paiement des dépenses approuvées sur fonds fléchés (voyages, matériel, conférences) ; signature des contrats par un officier de SPI ; remboursements, facturation et suivi des fonds par projet ; assistance juridique
- **Candidature** : discussion informelle avec un ou plusieurs membres du conseil, puis dossier formel à un membre du conseil parrain (détails du projet, services demandés, liaison, mode de désignation des successeurs), projet de résolution, discussion d'au moins trois jours en général, vote à une réunion publique mensuelle sur IRC ; la liaison dispose en général de 60 jours pour accepter

**Sources** : [SPI — projets](https://www.spi-inc.org/projects/) ; [SPI — Associated Project HOWTO](https://www.spi-inc.org/projects/associated-project-howto/) ; [SPI — services](https://www.spi-inc.org/projects/services/)

## NumFOCUS (parrainage fiscal)

- **Type** : parrain fiscal pour projets scientifiques ouverts
- **Structure** : NumFOCUS, qui se présente comme l'entité légale des projets sous parrainage fiscal
- **Frais** : non précisés sur les pages consultées
- **Licence** : licence open source standard ; la page précise « An OSI approved license »
- **Éligibilité** : trois critères généraux : projet à orientation scientifique (« Be scientifically oriented »), ouvert (« Be open » : licence standard, engagement public, plus d'un contributeur, décisions réparties et non concentrées dans une seule institution), bienveillant (« Be kind » : code de conduite public avec procédure de signalement). Le parrainage fiscal ajoute une gouvernance explicite publiée sur le site ou la documentation, et une feuille de route des chantiers prioritaires. La page indique que ce niveau d'exigence est plus élevé que celui de l'affiliation.
- **Services** : juridique (licences, dépôt et propriété des marques, contrats), financier (comptes fournisseurs et clients, administration de subventions, contrats de prestataires, impôts et rapports), opérationnel (infrastructure technique, organisation de conférences, conseil sur les demandes administratives)
- **Candidature** : procédure décrite sur la page « Overview & How to Apply »

**Source** : [NumFOCUS — Overview & How to Apply](https://numfocus.org/projects-overview)

## Open Collective Europe

- **Type** : parrain fiscal pour projets de l'écosystème open source
- **Structure** : Open Collective Europe, dont l'association devient Open Source Europe selon une mise à jour du 16 février 2026 ; la fondation Open Collective Europe Foundation garde son nom
- **Frais** : 8 % plus frais Stripe ou PayPal pour les contributions en ligne ; 10 % pour les virements bancaires ; 10 % pour les dons déductibles et les subventions
- **Licence** : non précisée ; la page renvoie aux conditions complètes dans un document externe
- **Éligibilité** : le projet doit s'aligner sur la mission « supporting the open source ecosystem » ; les fonds ne servent qu'aux activités du projet et ne peuvent pas profiter à des particuliers ; pas de campagne politique ou religieuse. Le projet conserve la propriété de sa propriété intellectuelle et de sa marque. La déductibilité fiscale dépend du donateur.
- **Candidature** : bouton « Apply » sur la page d'hébergement ; la candidature vaut acceptation des conditions de l'hébergeur ; étapes non détaillées

**Sources** : [Open Collective Europe](https://opencollective.com/europe) ; [Open Collective Europe — candidature](https://opencollective.com/europe/apply)

## Commonhaus Foundation

- **Type** : fondation à but non lucratif agissant comme hébergeur fiscal (« fiscal host »)
- **Structure** : Commonhaus Foundation
- **Frais** : non précisés
- **Licence** : non précisée
- **Éligibilité** : la page décrit son modèle comme conçu pour des projets open source établis et autogouvernés ; critères formels non précisés
- **Services** : accès au financement par GitHub Sponsors et Open Collective, « Minimum viable governance », foyer à long terme pour le projet
- **Candidature** : non précisée sur la page d'accueil

**Source** : [Commonhaus Foundation](https://www.commonhaus.org/)

## Linux Foundation (hébergement de projets)

- **Type** : fondation d'hébergement de projets
- **Structure** : Linux Foundation
- **Frais** : non précisés ; la page indique que l'adhésion ou le financement ne sont jamais requis pour contribuer aux projets financés
- **Licence** : aucune licence nommée ; le modèle de propriété intellectuelle doit suivre les bonnes pratiques open source et être documenté
- **Éligibilité** : gouvernance ouverte et transparente ; marques, comptes de dépôt git et actifs similaires détenus de façon neutre par la fondation ; au moins un membre de la Linux Foundation et cinq organisations qui parrainent le projet
- **Services** : fonctions fiduciaires, juridiques et de développement d'écosystème ; plateforme LFX ; formation et certification ; événements ; infrastructure, communication, croissance de la communauté, finance et opérations, RH, recherche. Trois modèles : projet communautaire, projet communautaire avec financement, communauté parapluie avec financement.
- **Candidature** : non précisée sur la page

**Source** : [Linux Foundation — hébergement de projets](https://www.linuxfoundation.org/projects/hosting)

## Apache Software Foundation (Incubateur)

- **Type** : fondation d'hébergement de projets, entrée par l'Incubateur
- **Structure** : Apache Software Foundation
- **Frais** : non précisés sur les pages consultées
- **Licence** : non précisée sur les pages consultées ; les committers signent un accord de contribution individuel (ICLA) qui permet de publier sous la licence Apache
- **Éligibilité** : l'entrée à l'Incubateur est décidée par un vote ; il faut un parrain (« Champion ») avant de rédiger la proposition formelle
- **Candidature** : proposition en texte brut envoyée à la liste générale avec l'objet préfixé « [PROPOSAL] », discussion sur la liste, puis vote d'entrée

**Sources** : [Apache Incubator — proposer un projet](https://incubator.apache.org/guides/proposal.html) ; [ASF — gouvernance](https://www.apache.org/foundation/governance/)

## Eclipse Foundation

- **Type** : fondation d'hébergement de projets
- **Structure** : Eclipse Foundation
- **Frais** : la page consultée (Eclipse Membership) ne mentionne pas de frais d'hébergement de projet ; la cotisation des membres dépend de la classe d'adhésion et du chiffre d'affaires. « There is no cost to being a Committer member of the Foundation. »
- **Licence** : le manuel du projet demande d'adopter une licence approuvée par l'OSI et un fichier LICENSE avec le texte complet à la racine du dépôt ; les projets de premier niveau définissent la licence standard de leurs projets
- **Éligibilité** : la proposition contient au minimum une description, une déclaration de périmètre et la liste des responsables et committers initiaux ; marques et domaines transférés avant la revue de création ; Git est le seul système de gestion de versions autorisé
- **Candidature** : proposition par formulaire web (privée au départ), publication par l'EMO, revue communautaire d'au moins deux semaines, revue de création d'environ une semaine, puis provisionnement

**Sources** : [Eclipse — manuel des projets](https://www.eclipse.org/projects/handbook/) ; [Eclipse — adhésion](https://www.eclipse.org/membership/)

## OpenJS Foundation

- **Type** : fondation d'hébergement de projets JavaScript
- **Structure** : OpenJS Foundation
- **Frais** : aucun frais d'hébergement de projet sur la page projets ; cotisations des membres organisationnels sans montant
- **Licence** : la liste de contrôle d'intégration demande des licences compatibles avec les exigences de la fondation, un fichier LICENSE.md, la signature d'un accord de contribution de projet et l'adoption d'un CLA ou d'un DCO
- **Éligibilité** : projet prêt à passer à une gouvernance ouverte ; adoption du code de conduite OpenJS ; document Governance.md requis pour le stade « Impact »
- **Candidature** : processus d'incubation supervisé par le Cross Project Council ; stades : Impact, At-Large, Incubation, Feature Complete, Sunsetting, Archived

**Sources** : [OpenJS — projets](https://openjsf.org/projects) ; [OpenJS — progression des projets](https://github.com/openjs-foundation/cross-project-council/blob/main/PROJECT_PROGRESSION.md)

## Rust Foundation Maintainers Fund

- **Type** : fonds de dons d'un projet, qui finance des mainteneurs de façon stable
- **Structure** : Rust Foundation, avec l'équipe Funding du projet Rust qui communique avec les équipes et les sponsors
- **Fonctionnement** : le fonds collecte des dons pour fournir un financement stable aux contributeurs qui maintiennent des zones critiques de la chaîne d'outils Rust. L'équipe Funding sélectionne les « Maintainers in Residence » financés.
- **Montant** : non précisé sur la page
- **Licence** : non précisée
- **Éligibilité** : contributeurs du projet Rust, choisis par l'équipe Funding ; aucune procédure de candidature décrite sur la page
- **Candidature** : non précisée. Les dons passent par GitHub Sponsors de la Rust Foundation.
- **À côté du fonds** : la page liste des contributeurs du projet Rust qui ont leur propre compte GitHub Sponsors

**Source** : [Rust — financement](https://rust-lang.org/funding/)
