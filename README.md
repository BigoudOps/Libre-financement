# Libre Financement

Les moyens de financer le développement d'un logiciel libre, hors sponsors GitHub et Ko-fi : subventions, fonds privés, financements par les entreprises, plateformes et modèles de licence. Pour chaque programme : montant, licence demandée, conditions, candidature, exemples et sources.

Toutes les informations ont été relevées sur les pages officielles des programmes en octobre 2026. Ce qu'une page ne dit pas est écrit « non précisé ». Les dates limites et les statuts d'ouverture ne figurent pas ici : ils changent, la page officielle de chaque programme fait foi.

## Par catégorie

- [Fonds privés](fiches/fonds-prives.md) : GitHub Secure Open Source Fund, FLOSS/fund, Alpha-Omega, Open Technology Fund, Codex for Open Source
- [Entreprises](fiches/entreprises.md) : Open Source Pledge, thanks.dev
- [Plateformes](fiches/plateformes.md) : Open Collective, Liberapay, Tidelift
- [Modèles économiques](fiches/modeles-economiques.md) : Fair Source, double licence
- [Historique](fiches/historique.md) : programmes terminés ou ponctuels
