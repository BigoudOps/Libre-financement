# Libre Financement

Il existe pas mal d'aides pour financer des projets libres, mais on ne les connaît pas. Je les ai rassemblées ici.

[![github-watchers](https://img.shields.io/github/watchers/BigoudOps/Libre-financement?label=Watch&style=social&logo=github)](https://github.com/BigoudOps/Libre-financement)
[![github-stars](https://img.shields.io/github/stars/BigoudOps/Libre-financement?style=social&logo=github)](https://github.com/BigoudOps/Libre-financement)
[![github-forks](https://img.shields.io/github/forks/BigoudOps/Libre-financement?label=Fork&style=social&logo=github)](https://github.com/BigoudOps/Libre-financement)

Un annuaire en français pour trouver de quoi financer un projet libre,
sans passer par GitHub Sponsors ou Ko-fi. Le logiciel est concerné, mais
pas seulement : matériel, contenus, données, tout ce qui est publié sous
licence libre.

Chaque fiche donne le montant, la licence demandée, les conditions et la
façon de candidater, avec le lien vers la source. Quand je n'ai pas
l'info, c'est écrit « non précisé ».

Les montants, conditions et dates changent. Avant de candidater, vérifiez
sur la page du programme.

Un programme manquant, une page qui a changé, une erreur ? [Ouvrez une issue](https://github.com/BigoudOps/Libre-financement/issues/new/choose) ou lisez [comment contribuer](CONTRIBUTING.md).
